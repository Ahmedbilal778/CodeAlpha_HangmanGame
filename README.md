
# CodeAlpha Hangman Game

## About the Project
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word by entering one letter at a time.

## Features
- Random word selection
- Five predefined words
- Maximum six incorrect guesses
- Letter-by-letter guessing
- Input validation
- Win and lose conditions

## Technologies Used
- Python
- Random Module

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python hangman.py
```
